# 💗 You Unlocked A Secret Character

A tiny retro confession game. Ridiculously easy levels, one final boss: THE CONFESSION.

Levels:
- That smile
- Late-night thoughts
- Songs that remind me of you
- Things I never said
- Final Boss: THE CONFESSION → Achievement Unlocked: Someone likes you → [Wanna know who?]

Made with 💗 by [@the.dev.adi](https://github.com/thedevadi)

Play: WASD / Arrows + Space. Mobile supported.
